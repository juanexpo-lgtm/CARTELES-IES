Cómo usarlo en Windows
  1. Guarda este archivo en una carpeta fija y ábrelo con Edge o Chrome.
  2. Elige una plantilla o añade zonas. Selecciona cada zona y añade su contenido. Mueve y redimensiona las zonas en el editor o usa los porcentajes.
  3. Cada zona reproduce su lista de forma independiente. El reloj no necesita archivos. Las zonas sin contenido muestran su fondo.
  4. Pulsa «Iniciar emisión». Mueve el ratón para mostrar controles. Escape sale de pantalla completa; «Salir» vuelve al editor.
  5. La salida HDMI distribuye esta misma imagen a las seis pantallas ya conectadas.

Imágenes: JPG, PNG, WebP y GIF. Vídeos: MP4 (preferiblemente H.264) o WebM, siempre que el navegador admita su codificación. PDF y PowerPoint deben exportarse a imágenes o vídeo.

Los vídeos se reproducen hasta el final. La duración indicada solo afecta a imágenes y avisos. Espacio pausa todas las zonas; flecha derecha avanza todas las listas. Los relojes siguen mostrando la hora real. El silencio general prevalece sobre el sonido de cada zona. El formato de composición se conserva con bandas negras si no coincide con la pantalla.

Se intenta conservar la lista en este navegador. Haz una copia con «Exportar copia»: incluye los archivos. Si cambias de navegador, borras sus datos o mueves el HTML, puede ser necesario importarla. No uses modo privado. Las copias de vídeos grandes pueden consumir bastante memoria.

Para una emisión continua, evita que Windows suspenda el PC. El programa no se inicia solo al encender Windows: abre el archivo y pulsa «Iniciar emisión». Los horarios solo actúan mientras la emisión está abierta.

Emisión

Hora local del PC. Fuera de horario: pantalla negra y sin sonido. Para horario nocturno, el día seleccionado es el de inicio. Horas iguales = 24 horas.
